# 单链表操作与经典算法练习（C语言实现）

用C语言实现的单链表工具集，涵盖基础增删查改操作和几道链表经典算法题（反转、快慢指针找中点、判断环）。所有功能均可通过命令行菜单交互测试。

## 功能列表

**基础操作**
- 建立链表（尾插法批量输入）
- 打印链表
- 按值查找
- 按位置查找
- 插入节点（支持插入到任意合法位置，含边界检查）
- 删除节点（按值删除，含边界检查）

**经典算法题**
- 反转链表（三指针法：prev / curr / next）
- 查找中间节点（快慢指针，偶数长度返回偏后节点）
- 判断链表是否有环（快慢指针，Floyd判圈算法）

**调试工具**
- 手动将链表首尾相连造出一个环，用于验证判环算法的正确性
- 断开环，恢复链表正常结构

## 技术要点

- `insert` / `delete` 操作中同步维护 `head`、`tail` 两个指针以及节点计数 `num`，避免出现悬空指针或状态不一致（比如删除尾节点后 `tail` 未更新导致的野指针问题）
- 所有查找/删除类操作均对空链表和越界位置做了防御性判断，避免对 `NULL` 指针解引用导致程序崩溃
- `reverseList` 使用三指针法原地反转，时间复杂度 O(n)，空间复杂度 O(1)
- `fideMiddle` 和 `hasCycle` 均使用快慢指针技巧：慢指针每次走一步，快指针每次走两步，前者用于定位中点，后者用于检测环（若存在环，两指针必然在环内相遇）
- 专门编写了"造环/断环"调试功能，在没有内建单元测试框架的情况下，用最直接的方式验证了判环算法在真实成环场景下的正确性

## 开发过程中踩过的坑（简单记录）

- `while(temp->data != value && temp != NULL)` —— `&&` 短路求值的顺序问题，`temp` 为 `NULL` 时先访问 `temp->data` 导致越界访问，应改为 `temp != NULL && temp->data != value`
- `if(fast = slow)` —— 把比较运算符 `==` 误写成赋值运算符 `=`，导致条件恒为真，判环逻辑完全失效
- 删除尾节点后忘记同步更新 `tail` 指针，导致后续操作访问到已被 `free` 的内存（悬空指针）
- 对 `int*` 类型的参数直接执行 `num--`，实际修改的是指针本身而非其指向的值，应写成 `(*num)--`
- `switch` 语句中某个 `case` 分支末尾漏写 `break`，导致执行完当前分支后"穿透"到下一个分支，程序行为与预期不符
